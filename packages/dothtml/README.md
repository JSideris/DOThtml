# DOThtml

**DOThtml** is a client-side TypeScript UI framework engineered for high-performance applications. By bypassing the Virtual DOM and updating elements directly via Signals, it achieves superior performance while maintaining a tiny footprint (22.4kB).

## Start Here

**Documentation:** [https://dothtml.org/](https://dothtml.org/)  
**AI Agent Guide:** [https://dothtml.org/docs/ai-agents.md](https://dothtml.org/docs/ai-agents.md)

## Installation

```bash
npm install dothtml
```

## Quick Start

```typescript
import { dot } from 'dothtml';

dot("body").h1("Hello DOThtml!");
```

For more examples and comprehensive documentation, visit [dothtml.org](https://dothtml.org/).
